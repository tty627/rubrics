### 步骤 2: 展示快速统计（1分钟）

- "准则数从 6.1 条增加到 30.5 条"
- "生成了 1,385 种不同的维度名称，覆盖多学科"

### 步骤 3: 展示典型案例（3-5分钟）
打开 `case_example.md`，重点看：
- 第 1 节"原始问题"和"对比表格"

- 第 6 节"Phase 3 优势"（4 个优势）

**指着表格说**:
- "这是会计学的题目，问合同负债和应付账款"

- "Phase 3 生成了 3 个维度，19 条准则，85 分，而且每条都有明确的正向/负向表述"
- "这 3 个维度对应题目的 3 个子问题，结构很对齐"

### 步骤 4: 说明下一步计划（1分钟）
